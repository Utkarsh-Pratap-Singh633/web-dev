About ME

I’m Utkarsh, a B.Tech student and aspiring software developer currently focused on building a strong foundation in Java, Data Structures & Algorithms, and Web Development.

Right now, I’m working consistently on improving my problem-solving skills through DSA while learning how to build real-world projects. My journey includes Core Java, OOP, Collections, File Handling, HTML, and gradually expanding toward full-stack and backend development. I believe in learning publicly and building consistently. I regularly share my progress, coding journey, projects, and lessons on platforms like X and LinkedIn.

My current priorities are:
* ☕ Mastering Java
* 🧩 Solving DSA problems consistently
* 🌐 Learning Web Development
* 🔨 Building projects instead of only consuming tutorials
* 📚 Improving my fundamentals through revision and practice
* 💻 Building a strong GitHub portfolio
* 🚀 Preparing for internships and software development roles

My larger goal is to become a capable software engineer—not just someone who knows syntax or completes courses. The focus is on developing strong fundamentals, problem-solving ability, and enough practical experience to build things independently. I’m still early in the journey, and there are gaps to fill—especially in advanced development and interview-level problem solving. But the direction is clear: learning, deliberate practice, projects, and public accountability. Currently: Solving DSA. Learning Development. Building in Public. 🚀
